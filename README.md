## Runtime Defines

- `BUNCOP_API_BASE`: base URL API (contoh `http://localhost:8000/api/v1`)
- `BUNCOP_SYNC_BASE`: override URL sync incubator (opsional)
- `BUNCOP_SYSTEM_ACTIVITY_KEY`: service key untuk kirim system activity log saat token user kosong
